    Privacy & Capture

    Standard Mode (default)

    Capture a page only when you explicitly trigger it -- right-click the page or the toolbar icon, or use the keyboard shortcut. No special permissions needed.

    Power Mode

    Show a capture button automatically on webpages that look capturable.
    Power Mode requires permission to read webpage content on sites you visit. Chrome will ask you to allow this before it turns on.
